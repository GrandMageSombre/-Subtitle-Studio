# 审查报告 3 · 字幕工坊 Subtitle Studio v0.2.1（交互修复轮）

- 审查时间：2026-10-15
- 审查方式：两轮子智能体（交互逻辑正确性 / 代码质量与用户体验）→ 主智能体逐条回读源码核实 → Node+DOM 桩回归测试验证
- 本轮主题：修复两个用户反馈 ① 时间轴点击选播放点容易误拖字幕；② 画面字幕大小与位置难调
- 结论：**严重 2 项（全部修复）+ 建议 6 项（全部修复）+ 可选 2 项（修复）+ 已知限制 1 项**

---

## 一、修复内容（对应用户反馈）

| 反馈 | 修复 |
| --- | --- |
| ① 播放时难选播放点，一碰字幕就把它挪了 | 时间轴引入 **5px 拖动阈值**：`pointerdown` 先进入 pending，位移超过阈值才升级为移动/改时长；未超过阈值松手 = **跳转到点击处**（同时选中该条）。空白区域仍按下即定位、松手跳转 |
| ② 字幕大小和位置不好调 | 播放控制条新增 **字号滑块（12–44px）** 与 **位置滑块（距底 0–90%）**，实时预览画面叠加层，`change` 时写入 localStorage 持久化；帮助文案同步更新 |

附加健壮性：左键限定（右键不触发拖动）、`setPointerCapture`（窗口外松手不再“幽灵拖动”）、`pointerdown` 事件链（顺带获得触屏点按/拖动能力）、拖动中 `grabbing` 光标、拖动阈值按水平+垂直合成位移（hypot）判定。

## 二、本轮审查发现与修复

### 严重（2 项，全部修复）

| # | 位置 | 问题 | 后果 | 修复 |
| --- | --- | --- | --- | --- |
| 1 | app.js 拖动逻辑 | 重构时把按下时刻存为 `drag.t`，消费端仍读 `drag.t0` | `dt = NaN` → 字幕时间全变 NaN，时间轴错乱并污染自动保存 | 补回 `t0` 字段；并新增 `tests/ui_logic_test.cjs` 断言「拖动后 start/end 为有限数且约等于预期位移」，把该类错误固化为回归测试 |
| 2 | app.js 顶部 `localStorage.getItem` | 隐私模式/禁用存储时抛错，且位置在模块顶层 | 整页白屏（旧代码只在 init 内，降级为功能不可用） | 新增 `lsGet/lsSet` 安全封装，替换全部 5 处直接调用 |

### 建议（6 项，全部修复）

| # | 问题 | 修复 |
| --- | --- | --- |
| 3 | `setPointerCapture(e.pointerId)` 挂在 MouseEvent 上取不到 pointerId，捕获从未生效 | 时间轴三监听改为 `pointerdown/pointermove/pointerup`，并保留 try/catch 兜底 |
| 4 | 窗口外松手 / 切标签后回到窗口继续“幽灵拖动” | 指针捕获 + `window.blur` / `pointercancel` 双重兜底清空 `drag` |
| 5 | 阈值只算水平位移，纯竖向小幅抖动误判为点击 | 改用 `Math.hypot(dx, dy)` |
| 6 | 预览在未勾选“字幕”或无字幕时静默返回，滑块显得失效 | 预览时强制显示一次；无字幕时用「字幕预览效果」占位文本 |
| 7 | 1800ms 魔法数字、localStorage key 散落 4 处 | 提为 `PREVIEW_HIDE_MS`、`LS_SUB_FONT/LS_SUB_POS` 常量 |
| 8 | `previewSubStyle` 与 `updateOverlay` 重复显隐/文本逻辑 | 抽出 `showOverlayText/hideOverlay`，两处共用 |

### 可选（2 项，已修复）

| # | 问题 | 修复 |
| --- | --- | --- |
| 9 | 拖动中无光标反馈 | 拖动中设 `grabbing` / `ew-resize`，结束与取消时复位 |
| 10 | 滑块缺读屏语义 | `applySubStyle()` 同步 `aria-valuetext`（“19像素”“距底部 7%”） |

### 已知限制（1 项，记录不修）

- 极短字幕（时间轴上 < 16px 宽）只有整体移动、没有边缘拖拽把手；调整其时长请用列表里的起止时间输入框（有 1ms 精度）。

## 三、验证

- **新增交互回归测试** `tests/ui_logic_test.cjs`（Node + 轻量 DOM 桩，无需浏览器），4 个用例全部通过：
  1. 色块单击（位移 2px）→ 跳转到 ~5s 且**字幕不动、不触发保存**
  2. 拖动 40px → 第二条字幕 4–6s 平移为 ~5.5–7.5s，**时间有限非 NaN**
  3. 右键 → 不跳转、不改字幕
  4. 字号/位置滑块 → 叠加层即时生效 + 预览可见 + localStorage 持久化
- `node --check` 语法通过；pytest **91 项全过**（含新增的 UI 逻辑用例，已包装为 `tests/test_ui_logic.py`，无 Node 时自动跳过）
- `tests/test_consistency.py::test_js_dom_ids_exist` 持续守护 JS 与 DOM id 一致（本次新增的 4 个控件 id 由此校验通过）
