## 一、本轮改动

- **ASS/SSA 格式**：`to_ass`（v4+ 模板、厘秒时间戳、换行转 `\N`）、`parse_ass`（Format 字段定位、逗号文本保护、标签剔除、无 Format 行回退 v4 十字段）、`parse_auto` 三格式判别；导出菜单与导入 accept/拖拽同步放行
- **中文字形选项**：识别设置新增 `script`（auto/simplified/traditional），OpenCC 词汇级转换（tw2sp/s2twp），设置随任务持久化
- **导出查表化**：`EXPORT_FORMATS` 改为 fmt → (mime, ext, serializer)，消化第四轮遗留项 L1
- **文档归拢**：版本说明.md `git mv` 至 docs/，全库链接同步；新依赖 opencc-python-reimplemented 入 spec 整体收集

## 三、误报澄清

- 线程视角提出「OpenCC 实例多线程共用风险」：经核实，唯一生产调用点处于 `_TRANSCRIBE_LOCK` 串行段内，且 opencc-python-reimplemented 为纯 Python 只读查表，无竞态；本轮进一步把转换移出锁后，CPython dict 读原子性仍保证安全。
- 「config 失败时下拉为空」：与 selModel 等既有行为一致，非本轮引入，不计问题。
