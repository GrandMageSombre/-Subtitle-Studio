## 版本详情

### v0.3.0（2026-10-15）— ASS 字幕格式 + 中文字形选项

**新增功能**

- **ASS/SSA 字幕格式**：导出新增 ASS（v4+ 模板、厘秒时间戳、多行转 `\N`、带 BOM），**必剪、剪映可直接导入**；导入同步支持 ASS/SSA（按 Format 行定位字段、逗号文本保护、剔除 `{...}` 特效标签、`\N`→换行、`\h`→空格、无 Format 行回退 v4 十字段）；整窗拖拽与文件选择器放行 .ass/.ssa
- **中文字形选项**：识别弹窗新增「中文字形」下拉——Whisper 对中文的输出简繁不定，现可强制 **简体中文** / **繁体中文**；OpenCC 词汇级转换（軟體→软件、软件→軟體），默认「自动」保持识别原样；选项随任务设置持久化

**框架变化**

- 导出端点查表化：`EXPORT_FORMATS` 改为 fmt → (MIME, 扩展名, 序列化函数)，新增格式只需登记一行（消化第四轮遗留项 L1）
- 新依赖 `opencc-python-reimplemented`（纯 Python，自带词典）；spec 整体收集 `opencc` 含词典数据
- **文档归拢**：版本说明.md 迁入 `docs/`（git mv 保留历史），全部文档集中 docs/（README 与 LICENSE 留根目录），全库链接同步更新

**本轮审查修复摘要（审查报告5.md，1 关键 + 7 建议）**

- 关键（1）：`parse_ass` 把小写 `\n` 转换行，路径类字面量（`C:\new`）回读静默损坏 → 小写 `\n` 保留原样
- 建议（7）：`parse_auto` 误判正文含 `[events]` 的 SRT（改为行首段标记）、ASS 导出加 BOM 防必剪/剪映 ANSI 乱码、字形转换移出转录锁、OpenCC 构造失败负缓存 + 日志带根因、界面文案补中文字形与 ASS 说明、README/docstring 同步五格式、dist 副本同步
- 遗留（5）：厘秒浮点舍入特性、拖拽双触发（既有）、花括号不转义（规范无解）、`\N`/`\h` 字面量有损（已声明）、srt.py 拆分暂缓

**测试**

- 新增 27 项用例（ASS roundtrip 15 组随机种子、判别/误判/反斜杠/BOM、简繁转换）；pytest **118 项全过**；`node --check` 通过；exe 冒烟实测

**已知限制**

- ASS 导出仅保留文本与时间轴（Default 样式），不含字号/位置等编辑器样式信息

### v0.2.3（2026-10-15）— 重新打包前复查修复

**严重修复（1）**

- **重启后导入任务字幕被清空**：`_restore` 把未完成任务翻转 error 时，在读取 segments.json 之前就落盘，空 segments 覆写已有字幕；且导入任务从不置 `done`（永远 `queued`），每次重启必触发。修复：恢复顺序改为先读字幕再落盘（jobs.py）；导入完成即置 `done`（main.py）

**关键修复（5）**

- 删除接口不再放行进行中任务（返回 409）：此前 Windows 下媒体文件被识别线程占用删不掉，留残缺目录且识别线程空跑
- 时间轴拖动中窗口失焦/指针取消时，改动照常排序并保存（此前直接丢弃拖拽状态，字幕已改但不落盘、顺序不变量被破坏）
- 启动新识别任务前取消旧任务的待保存并清空编辑态：修复旧字幕被防抖保存写入新任务 id、识别完成无条件覆盖期间编辑的竞态
- 识别进行中禁止再开识别 / 导入字幕（前端入口拦截并提示）
- 导入任务在 `_restore` 中的提示语误述随状态闭环消除

**建议修复（4）**

- 字幕时间拒绝 NaN/Infinity：接口校验 422（main.py）、解析清洗跳过（srt.py），杜绝 nan 落盘后导出 500
- 输入框内 Ctrl+Z/Y 放行原生文本撤销，不再被全局快捷键拦截
- 撤销/重做后主动刷新画面字幕叠加层（此前只改文本不换索引时残留旧字幕）
- `loadJobData` 统一清理保存定时器与状态（`cancelPendingSave`）

**文档修复（文档审查1.md）**

- **版本说明回归版本控制**：此前仅存在于被 gitignore 的 `dist/`，推送即丢失；现以仓库根目录为正本，dist/ 保留分发副本；README 与 reviews 索引中的失效链接随之恢复
- README 项目结构补列 LICENSE 与 `backend/__init__.py`；路线图「字幕翻译」注明区别于已实现的 Whisper 内置英译

**测试**

- pytest 全套回归通过；`node --check` 通过（详细结果见审查报告4.md）

### v0.1.0（2026-10-15）— 首个可用版本

**新增功能**

- **语音识别**
  - 上传视频/音频（mp4/mov/mkv/webm/mp3/wav/m4a 等，PyAV 可解码即可），本地 faster-whisper（CPU int8）识别生成带时间轴的字幕
  - 模型可选 tiny / base / small（默认）/ medium / large-v3，界面显示体积与适用场景
  - 语言自动检测或指定（中文/粤语/英语/日语等 18 种）；任务支持「原语言识别」与「翻译成英语」
  - 基于词级时间戳的**按标点断句**：句末标点切分（排除小数 `3.5` 与缩写 `Mr.` 里的句点）、过短碎片合并、超长单句按词硬切（阈值 `MIN_CUE_DURATION/MIN_CUE_CHARS/HARD_DURATION` 可调）
  - VAD 过滤 + beam search 5，识别进度实时回调（按音频时间百分比）
  - huggingface.co 不可达时自动切换 hf-mirror 镜像并禁用 Xet（镜像 401 问题）；加载失败时自动禁用 Xet 重试一次
  - PyAV 19 兼容：`requirements.txt` 钉 `av>=14.4,<19` + 运行时 `av.open` 兼容补丁双保险
- **在线编辑**
  - 视频播放器 + 字幕叠加显示 + 时间轴 + 字幕列表四联动
  - 列表内直接编辑文本与起止时间（`时:分:秒.毫秒`，非法输入红框提示且不写入）
  - 时间轴：点击跳转、拖动色块整体移动、拖边缘改时长、Ctrl+滚轮缩放（1x~200x）、自定义滚动条、双击复位；拖拽结束后自动排序维持「有序」不变量
  - 工具栏：添加 / 删除 / 合并下一条 / 播放处拆分 / 按标点拆分 / 整体平移（支持从选中条起）
  - 快捷键：空格播放、←→快进快退、Enter 播段、`[`/`]` 对轴、Delete 删除、Ctrl+Z/Y 撤销重做
  - 重叠检测：与上一条时间重叠的条目红色高亮并统计
  - 编辑自动保存（防抖 1.2s + 页面关闭前 keepalive 保存），服务重启后自动恢复上次任务；识别在后台运行时顶栏显示全局进度条
- **导入导出**
  - 导入 SRT / VTT（UTF-8/GBK 自动判别，兼容 BOM、CRLF、缺序号、空文本块、NOTE 块、VTT 设置参数）
  - 导出 SRT / WebVTT / TXT / JSON，中文文件名按 RFC 5987 编码
  - 纯字幕编辑模式：导入字幕后可「本地视频」按钮浏览器直载预览（不上传）
  - 整窗拖拽：拖入 .srt/.vtt 走导入，拖入媒体走识别
- **工程与安全**
  - 上传体积上限（识别默认 10GB 可调 / 字幕 20MB），超限即拒并清理，防磁盘与内存耗尽
  - 媒体流式播放端点支持 HTTP Range（206/416、后缀范围、畸形请求防护）
  - 任务持久化到 `data/jobs/<id>/`（job.json + segments.json），重启恢复；中断任务标记 error 并落盘
  - 前后端句末标点集一致性由测试静态校验；JS 引用的 DOM id 存在性由测试守卫

**框架变化**

- 后端：FastAPI + uvicorn，`backend/` 分层（main 路由 / asr 识别 / srt 格式 / jobs 任务）
- 前端：零依赖原生 HTML/CSS/JS（无构建步骤），`static/` 下三个文件
- 存储：本地文件系统（`data/`，已 gitignore），无外部数据库
- 测试：pytest，`tests/` 下 gen_vectors（向量生成）/ test_formats / test_asr / test_consistency（一致性守卫）/ test_e2e
